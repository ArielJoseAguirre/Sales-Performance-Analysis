\# Sales Performance Analysis



\## Descripción del proyecto



Proyecto de análisis de datos comerciales desarrollado con Excel 365, utilizando una base de datos ficticia de 500 ventas correspondientes al año 2025.



El objetivo es analizar el rendimiento de las ventas, los costos y los márgenes de los productos, identificar tendencias mensuales y presentar los principales indicadores mediante un dashboard interactivo.



\## Objetivos del análisis



\- Analizar las ventas totales y los costos.

\- Calcular el margen bruto y el porcentaje de margen bruto.

\- Identificar los productos con mejor rendimiento comercial.

\- Analizar la evolución mensual de las ventas.

\- Comunicar los resultados mediante indicadores y gráficos.



\## Herramientas utilizadas



\- Microsoft Excel 365.

\- Tablas dinámicas.

\- Fórmulas de cálculo.

\- Gráficos dinámicos.

\- Dashboard de indicadores.



\## Indicadores clave (KPI)



El dashboard presenta los siguientes indicadores:



\- Ventas totales.

\- Costos totales.

\- Margen bruto.

\- Porcentaje de margen bruto.
